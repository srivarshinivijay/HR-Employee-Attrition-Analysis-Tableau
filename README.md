📊 HR Analytics Dashboard – Employee Attrition Analysis (Tableau)
🔍 Project Overview

This project presents an interactive HR Analytics Dashboard built using Tableau to analyze employee attrition patterns based on the IBM HR Analytics dataset.
The objective of this project is to identify key attrition drivers and provide actionable workforce insights for HR decision-making.

🛠 Tool Used

Tableau Desktop – Data Visualization & Dashboard Design
Microsoft Excel – Data Preparation (if applicable)

📁 Dataset Information

Dataset: IBM HR Analytics – Employee Attrition & Performance
Total Employees: 1,470
Total Attrition: 237
Overall Attrition Rate: 16.1%

📌 Key Dashboard KPIs

Total Employees
Total Attrition
Attrition Rate (%)

📊 Dashboard Analysis Sections

1️⃣ Attrition by Department
Analyzes which departments experience higher employee exits.

2️⃣ Attrition by Job Role
Identifies specific job roles with high attrition risk.

3️⃣ Attrition Rate by Experience Level
Shows that employees with 0–3 years of experience have the highest attrition.

4️⃣ Attrition by Salary Slab
Highlights the impact of compensation on employee retention.

5️⃣ Attrition by Overtime
Demonstrates that employees working overtime have higher attrition rates.

6️⃣ Demographic Analysis
Breakdown of workforce by:
Age Group
Gender

💡 Key Insights Derived Using Tableau

Highest attrition observed among early-career employees (0–3 years).
Sales-related roles show higher attrition rates.
Employees in lower salary bands are more likely to leave.
Overtime is strongly associated with higher attrition.
Majority workforce falls in the 25–35 age group.

🎯 Business Value

This Tableau dashboard helps HR teams:
Identify high-risk employee segments
Optimize compensation strategies
Reduce overtime-related attrition
Improve workforce retention planning
